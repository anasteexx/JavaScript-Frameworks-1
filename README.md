# BLOOM — Інтернет-магазин квітів

## Лабораторна робота №1. Bootstrap

**Дисципліна:** Фреймворки JavaScript  
**Виконала:** Звоздецька Анастасія  
**Група:** 311  
**Спеціальність:** 122 Комп'ютерні науки

## Мета роботи

Ознайомитися з можливостями фреймворку Bootstrap та застосувати його компоненти для створення сучасного адаптивного вебінтерфейсу.

## Опис проєкту

BLOOM — адаптивний вебсайт інтернет-магазину квітів із каталогом авторських букетів, інтерактивним кошиком та формою оформлення замовлення.

## Використані технології

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.8
- Bootstrap Icons
- Google Fonts
- LocalStorage

## Функціональні можливості

- Адаптивне навігаційне меню.
- Каталог із 16 букетів.
- Фільтрація товарів за категоріями.
- Перегляд детальної інформації про товар.
- Додавання та видалення товарів із кошика.
- Зміна кількості товарів.
- Автоматичний розрахунок вартості замовлення.
- Розрахунок вартості доставки.
- Валідація форми замовлення.
- Карусель зображень.
- Спливаючі сповіщення.
- Світла та темна теми.
- Збереження кошика та теми через LocalStorage.

## Запуск проєкту

Для запуску необхідно відкрити файл index.html у браузері
або скористатися розширенням Live Server у Visual Studio Code.

Для завантаження Bootstrap, іконок та шрифтів необхідне
підключення до Інтернету.

## Переваги Bootstrap

- Швидке створення вебінтерфейсів.
- Готові інтерактивні компоненти.
- Зручна адаптивна сіткова система.
- Єдиний стиль оформлення елементів.
- Зменшення обсягу власного CSS-коду.

## Недоліки Bootstrap

- Додатковий обсяг CSS та JavaScript.
- Схожість стандартних інтерфейсів.
- Необхідність перевизначення стилів для унікального дизайну.
- Надлишковість деяких компонентів для простих вебсторінок.

## Особливості реалізації

Проєкт працює на клієнтській стороні без серверної частини
та бази даних. Оформлення замовлення є демонстраційним.

## Висновок

У ході лабораторної роботи було опрацьовано основні можливості
Bootstrap 5.3.8 та створено адаптивний вебсайт інтернет-магазину

інтерактивний кошик, фільтрацію товарів, валідацію форм
